# Smart Pointers — C++

Учебный проект по реализации собственных умных указателей на C++17.

В проекте реализованы два шаблонных класса: `UnqPtr<T>` и `ShrdPtr<T>` для автоматического управления динамически выделенной памятью.

## Реализованные классы

### UnqPtr<T>

Умный указатель с уникальным владением объектом, аналогичный по назначению `std::unique_ptr`.

**Возможности:**
- Автоматическое освобождение памяти.
- Запрет копирования через `= delete`.
- Поддержка перемещающего конструктора и присваивания.
- Преобразование между совместимыми типами при наследовании.
- Перегрузка операторов `*` и `->`.
- Методы `get()`, `release()`, `reset()`, `is_null()`.
- Проверка состояния через `explicit operator bool()`.
- Исключения при обращении к пустому указателю.

Для корректного удаления объектов при преобразовании типов используются исходный адрес (`void* owner`) и указатель на функцию удаления (`deleter`).

### ShrdPtr<T>

Умный указатель с разделяемым владением объектом, аналогичный по назначению `std::shared_ptr`.

**Возможности:**
- Совместное владение объектом.
- Подсчёт владельцев через счётчик ссылок.
- Поддержка копирования и перемещения.
- Удаление объекта при уничтожении последнего владельца.
- Работа с наследованием и полиморфизмом.

## Поддержка массивов

Реализованы частичные специализации `UnqPtr<T[]>` и `ShrdPtr<T[]>`.

Они поддерживают `operator[]`, перемещение, управление владением и освобождение памяти через `delete[]`.

## Сборка и запуск

**Требования:**
- C++17
- CMake 3.20 или новее
- Интернет для первоначальной загрузки Google Test

Проект разработан с использованием CLion. Компоненты измерения памяти и dashboard ориентированы на Windows.

```bash
cmake -S . -B build
cmake --build build
```

Запуск тестов:

```bash
ctest --test-dir build --output-on-failure
```

## Пример использования

```cpp
#include <iostream>
#include <utility>
#include "include/unq_ptr.h"

int main() {
    UnqPtr<int> first(new int(10));
    UnqPtr<int> second = std::move(first);

    std::cout << *second << '\n';

    UnqPtr<int[]> array(new int[3]{1, 2, 3});
    std::cout << array[1] << '\n';

    return 0;
}
```

После перемещения `first` больше не владеет объектом. Память автоматически освобождается при уничтожении владельца.
