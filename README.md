#Smart Pointers — C++

Учебный проект по реализации собственных умных указателей на C++17.

В проекте реализованы два шаблонных класса: "UnqPtr<T>" и "ShrdPtr<T>", предназначенные для автоматического управления динамически выделенной памятью.

Основная цель работы — изучение принципов RAII, семантики перемещения, управления владением ресурсами, шаблонов C++ и работы с наследованием.

Реализованные классы

###UnqPtr<T>

Умный указатель с уникальным владением объектом, аналогичный по назначению "std::unique_ptr".

Основные возможности:

- Автоматическое освобождение памяти при уничтожении указателя.
- Запрет копирования через "= delete".
- Поддержка перемещающего конструктора и оператора присваивания.
- Передача владения между совместимыми типами при наследовании.
- Перегрузка операторов "*" и "->".
- Методы "get()", "release()", "reset()", "is_null()".
- Проверка состояния через "explicit operator bool()".
- Обработка обращения к пустому указателю с помощью исключений.

Для корректного удаления объектов при преобразовании между типами используются исходный адрес объекта ("void* owner") и указатель на функцию удаления ("deleter").

###ShrdPtr<T>

Умный указатель с разделяемым владением объектом, аналогичный по назначению "std::shared_ptr".

Основные возможности:

- Совместное владение динамически выделенным объектом.
- Подсчёт количества владельцев с помощью счётчика ссылок.
- Поддержка копирования и перемещения.
- Автоматическое удаление объекта при уничтожении последнего владельца.
- Работа с наследованием и полиморфизмом.
- Доступ к управляемому объекту через перегруженные операторы.

В отличие от "UnqPtr", класс "ShrdPtr" позволяет нескольким указателям одновременно владеть одним объектом.

###Поддержка динамических массивов

Для обоих классов предусмотрены частичные специализации шаблонов:

- "UnqPtr<T[]>"
- "ShrdPtr<T[]>"

Они обеспечивают управление динамическими массивами, доступ к элементам через "operator[]" и корректное освобождение памяти с помощью "delete[]".

Сборка и запуск

Требования:

- Компилятор с поддержкой C++17.
- CMake версии 3.20 или выше.
- Подключение к интернету для первоначальной загрузки Google Test.

Проект разработан с использованием CLion. Компоненты измерения памяти и dashboard ориентированы на Windows.

Для сборки через CMake:

cmake -S . -B build
cmake --build build

Запуск тестов из каталога проекта:

ctest --test-dir build --output-on-failure

###Пример использования

#include <iostream>
#include <utility>
#include "include/unq_ptr.h"

int main() {
    UnqPtr<int> first(new int(10));

    UnqPtr<int> second = std::move(first);

    std::cout << *second << '\n';

    UnqPtr<int[]> array(new int[3]{1, 2, 3});

    std::cout << array[1] << '\n';

    return 0;
}

После перемещения "first" больше не владеет объектом, а "second" становится его единственным владельцем.

При выходе из области видимости память автоматически освобождается.
