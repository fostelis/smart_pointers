# smart_pointers

Учебная реализация умных указателей `UnqPtr` и `ShrdPtr` на C++.

## Содержимое

- `include/` — реализации умных указателей.
- `tests/` — тесты Google Test.
- `benchmarks/` — измерения производительности и памяти.
- `dashboard/` — код визуализации результатов.
- `main.cpp` — пример использования.
- `CMakeLists.txt` — сборка проекта.

## Сборка

Откройте проект в CLion или используйте CMake:

```bash
cmake -S . -B build
cmake --build build
```
